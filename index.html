端末間の同期（GitHub）

記録をあなたのGitHubアカウントの非公開メモ（Gist）に保存し、パソコンと携帯で同じデータを使います。Gist権限だけのトークンを作り、各端末で一度だけ貼り付けてください。

トークンの作り方: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。Account permissions の「Gists」を Read and write にして作成。

データの書き出し・読み込み

端末の引っ越し・バックアップ用

「書き出す」で全記録をテキストにします。別の端末でこのアプリを開き、貼り付けて「読み込む」と同じ状態になります。

自動で決めるときのルール

  • 部位ごとの「回復にかかる日数」が経ってから同じ部位を鍛える（記録から学習、初期値は胸・背中・足3日、肩・腕2日、腹筋1日）
  • 痛みレベル2以上の部位は、その部位のメニューを外す
  • 私用・仕事で潰れた時間帯は避け、終日なら休み
  • 使える時間が40分未満なら短縮版F
  • 睡眠6時間未満・体調2以下の日は高負荷（胸・背中・足）を避ける
  • 週の目標回数に達したら休み。3日連続のあとは休みを優先
  • 胸と背中を優先し、足は設定した頻度を超えない
